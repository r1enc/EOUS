# EOUS Changelog
Version: 1.0
Status: Frozen
Owner: EOUS

---

# Purpose
This document records notable changes made to the EOUS project across released versions.
The changelog provides a historical record of project evolution without documenting implementation details or development discussions.

---

# Changelog Principles
The changelog should:
* Record released changes only.
* Remain chronological.
* Summarize user-visible or project-significant changes.
* Avoid implementation details.
* Reference official documentation when necessary.
