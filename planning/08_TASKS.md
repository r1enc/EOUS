# Purpose
This document defines how implementation work should be divided into executable development tasks.
Tasks represent the smallest unit of work assigned to an AI assistant or developer.

---

# Task Principles
Tasks should:
* Have one clear objective.
* Be independently implementable.
* Be independently reviewable.
* Be independently testable.
* Produce one logical Git commit.
