# Implementation Checklist
Version: 1.0
Status: Frozen 
Owner: EOUS

---

# Purpose
This checklist provides a quick verification guide for AI assistants before submitting implementation work.
Unlike the Definition of Done, this checklist is intended to be used as a practical step-by-step review.

---

# Documentation
* [ ] Relevant documentation has been read.
* [ ] Documentation priority has been respected.
* [ ] Documentation updates have been completed if required.

---

# Architecture
* [ ] Architecture rules have been followed.
* [ ] SDK rules have been followed when applicable.
* [ ] UI/UX rules have been followed when applicable.
* [ ] No architectural shortcuts have been introduced.

---

# Implementation
* [ ] Requested functionality has been completed.
* [ ] No unnecessary functionality has been added.
* [ ] Existing behavior has been preserved.

---

# Code Quality
* [ ] Code follows the Coding Standards.
* [ ] No duplicate logic exists.
* [ ] Naming is clear and consistent.
* [ ] Error handling is appropriate.

---

# Validation
* [ ] Build succeeds.
* [ ] Lint succeeds.
* [ ] Relevant tests pass.
* [ ] No known critical issues remain.

---

# Review
* [ ] Review Workflow has been completed.
* [ ] Implementation is ready for commit.
* [ ] Commit scope represents one logical change.
* [ ] Definition of Done has been satisfied.

---

# Goal
Provide a simple and repeatable verification process that helps AI assistants consistently deliver high-quality implementations.
