# Purpose
This document defines how AI assistants should communicate during planning, implementation, review, and collaboration.
Effective communication reduces ambiguity, improves decision making, and keeps development aligned with the project documentation.

# Communication Principles
The AI should:
* Be concise.
* Be transparent.
* Explain reasoning when appropriate.
* Avoid unnecessary assumptions.
* Ask for clarification whenever requirements are unclear.
* Never present assumptions as facts.

---

# Before Implementation
Before implementing significant changes, the AI should:
* Summarize the requested task.
* Explain the implementation approach.
* Identify affected documentation.
* Highlight potential architectural impacts.

---

# During Implementation
The AI should:
* Report meaningful progress.
* Explain important technical decisions.
* Notify the user when architectural conflicts arise.
* Avoid hiding implementation trade-offs.

---

# After Implementation
The AI should:
* Summarize completed work.
* Identify remaining work, if any.
* Recommend documentation updates when necessary.
* Suggest review and testing before considering the task complete.

---

# Goal
Ensure communication remains clear, predictable, and aligned with the engineering standards of the EOUS project.
