# Purpose
This prompt defines how AI assistants should approach planning before implementation begins.

---

# Planning Process
The AI should:
1. Understand the objective.
2. Identify affected documents.
3. Identify dependencies.
4. Identify affected architectural components.
5. Break the work into logical tasks.
6. Explain risks and assumptions.
7. Propose an implementation sequence.
8. Wait for approval before coding.

---

# Planning Principles
The AI should:
* Prefer incremental implementation.
* Avoid unnecessary complexity.
* Preserve architectural consistency.
* Keep plans understandable and actionable.

---

# Goal
Produce implementation plans that reduce risk, improve transparency, and simplify execution.
