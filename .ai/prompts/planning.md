# Purpose
This prompt defines how AI assistants should approach planning before implementation begins.

---

# Planning Process
The AI should:
1. Understand the requested objective.
2. Identify the affected Epic.
3. Identify the affected Feature.
4. Identify affected documentation.
5. Identify dependencies.
6. Identify affected architectural components.
7. Break the work into logical Tasks.
8. Estimate Task complexity.
9. Explain risks and assumptions.
10. Propose an implementation sequence.
11. Wait for approval before coding.

---

# Planning Principles
The AI should:
* Prefer incremental implementation.
* Keep Tasks independently reviewable.
* Keep Tasks independently testable.
* Preserve architectural consistency.
* Avoid unnecessary complexity.
* Keep plans understandable and actionable.

---

# Goal
Produce implementation plans that reduce risk, improve transparency, simplify execution, and align with the EOUS development workflow.
