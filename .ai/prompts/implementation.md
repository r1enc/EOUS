# Implementation Prompt
Version: 1.0
Status: Frozen 
Owner: EOUS

---

# Purpose
This prompt defines the standard behavior expected from AI assistants when implementing new functionality within the EOUS project.

---

# Instructions
Before writing any code, the AI should:
1. Understand the requested task.
2. Read the relevant documentation.
3. Identify affected architectural components.
4. Produce an implementation plan.
5. Wait for approval before implementation unless explicitly instructed otherwise.

During implementation, the AI should:
Follow the official documentation hierarchy defined in Documentation Rules.

After implementation, the AI should:
* Perform a self review.
* Verify Definition of Done.
* Update documentation if required.
* Recommend a commit message.

---

# Goal
Produce implementation that remains consistent with the EOUS architecture, engineering standards, and long-term vision.
