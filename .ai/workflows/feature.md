# Feature Workflow
Version: 1.0
Status: Frozen
Owner: EOUS

---

# Purpose
This document defines the standard workflow for implementing a new feature within the EOUS project.
Every feature should follow the same engineering process to maintain consistency, quality, and architectural integrity.

---

# Workflow

```text
User Request
      │
      ▼
Understand Requirements
      │
      ▼
Read Relevant Documentation
      │
      ▼
Create Implementation Plan
      │
      ▼
Wait for Approval
      │
      ▼
Implement
      │
      ▼
Self Review
      │
      ▼
Update Documentation (if required)
      │
      ▼
Commit
```

---

# Rules
The AI should:
* Never skip the planning phase.
* Read only the documentation relevant to the feature.
* Respect architectural boundaries.
* Implement incrementally.
* Keep changes focused on the requested feature.
* Review implementation before committing.

---

# Goal
Ensure every feature is implemented consistently and predictably.
