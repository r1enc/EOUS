# Purpose
This document defines how AI assistants should improve existing code without changing external behavior.

---

# Workflow

```text
Identify Improvement
      │
      ▼
Analyze Existing Implementation
      │
      ▼
Read Relevant Documentation
      │
      ▼
Create Refactor Plan
      │
      ▼
Wait for Approval
      │
      ▼
Refactor
      │
      ▼
Verify Behavior
      │
      ▼
Self Review
      │
      ▼
Commit
```

---

# Rules
The AI should:
* Preserve existing functionality.
* Avoid feature additions during refactoring.
* Improve readability and maintainability.
* Keep architectural consistency.
* Minimize unnecessary modifications.

---

# Goal
Improve code quality without changing platform behavior.
